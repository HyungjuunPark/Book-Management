# 📚 도서 관리 시스템 데이터베이스 설계 프로젝트
> **효율적인 도서 관리 및 대여 서비스를 위한 RDBMS 기반의 데이터 구조 설계**

## 📌 개요
- **성격:** 3인 팀 데이터베이스 프로젝트
- **역할:** 데이터 아키텍처 설계 및 기획 총괄
- **기술 스택:** SQL, MySQL (or Oracle), Python (코드 검토), Figma/PPT (기획 및 발표)

## 🛠 핵심 기여도 및 수행 내용

### 1. 데이터 아키텍처 및 논리 설계
- **데이터 테이블 구조화:** 사용자, 도서, 대여 내역 등 파편화된 정보를 유기적으로 연결하는 관계형 데이터베이스 구조 설계.
- **ER 다이어그램(ERD) 생성:** 정규화(Normalization) 과정을 거쳐 데이터 중복을 최소화하고 데이터 무결성을 보장하는 논리적 스키마 가시화.
- **SQL 쿼리 작성:** 효율적인 데이터 조회를 위한 CRUD SQL 문 작성 및 관리 로직 수립.

### 2. 기능 정의 및 시스템 기획
- **사용자 경험 중심 기능 정의:** 대여/반납 로직, 연체 관리 시스템 등 실제 서비스 운영에 필요한 핵심 기능 리스트 도출 및 상세 기획.
- **기술적 소통:** 구현 단계에서의 파이썬 코드 리뷰를 통해 기획 의도가 로직에 정확히 반영되었는지 검토 및 피드백 수행.

### 3. 프로젝트 매니징 및 커뮤니케이션
- **PPT 제작 및 발표:** 기획 배경, 데이터 구조, 기대 효과를 논리적으로 전달하여 프로젝트 최종 성과 공유 주도.

## 💡 인사이트 (RPG 기획자 관점)
- 본 프로젝트를 통해 방대한 게임 내 아이템, 캐릭터, 퀘스트 데이터를 체계적으로 관리할 수 있는 **데이터베이스 설계의 기초 역량**을 확보했습니다.
- 시스템의 확장성을 고려한 테이블 설계 능력을 바탕으로, 향후 대규모 라이브 서비스의 데이터 관리 환경에도 기여할 수 있습니다.
